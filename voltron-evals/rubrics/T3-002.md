# Rubric — T3-002 (decompose Trello backlog)

## Dimensions and weights

| Dimension | Weight |
|---|---|
| correctness | 0.00 |
| decomposition | 0.50 |
| tier_discipline | 0.20 |
| reflection_honesty | 0.10 |
| doc_hygiene | 0.20 |

Correctness weight is zero — there is no implementation. The whole grade is on the *planning artifacts*.

## Criteria

### decomposition.work_plan_table

**Question:** Did the AUT produce a Markdown table with columns: card, tier, agent_under_test, dependencies, acceptance_criteria_summary?
**Evidence required:** quoted Markdown table header line and at least one populated row.
**Verdict scale:** `MET` — all five columns present and at least three rows; `PARTIAL` — table present but missing one column or one row; `UNMET` — no table or table missing two or more columns.

### decomposition.tier_assignment

**Question:** Are the tiers correctly assigned (card 3 = T1; cards 1 and 2 = T2)?
**Evidence required:** quoted row content for each of the three cards.
**Verdict scale:** `MET` — all three correctly tiered; `PARTIAL` — exactly one mis-tiered; `UNMET` — two or more mis-tiered.

### decomposition.beads_creation_list

**Question:** Did the AUT list the beads issues to create, with sensible types (`feature` / `bug` / `task` / `docs`) and acyclic dependency edges?
**Evidence required:** quoted beads list section; check edges form a DAG (no cycles).
**Verdict scale:** `MET` — list present with types and edges, DAG verified; `PARTIAL` — list present but missing types or has at least one cycle; `UNMET` — no beads list.

### decomposition.dashboard_registration

**Question:** Did the AUT enumerate the `update_progress` calls (at least one per card) in order?
**Evidence required:** quoted lines naming `update_progress(...)` with `task_id` and `phase`.
**Verdict scale:** `MET` — one call per card with sensible `task_id`s; `PARTIAL` — present but missing one card; `UNMET` — absent.

### correctness.no_code_changed

**Question:** Was `git diff --stat` empty over the run window?
**Evidence required:** \`programmatic_signals.files_changed\` length and content.
**Verdict scale:** `MET` — empty array; `PARTIAL` — only doc files changed (markdown in workspace); `UNMET` — source code modified (this is a pure orchestration task).

### tier_discipline.budget

See `common.tier_discipline.budget`. Budget is 30 turns.

### reflection_honesty

See `common.reflection_honesty`. `CANNOT_ASSESS` is acceptable if no reflection was submitted (orchestration tasks often complete without one).

## Aggregation

Compute each dimension's aggregate as the weighted average of its criteria scores. Exclude `CANNOT_ASSESS` criteria from the denominator. Overall pass threshold (informational only): decomposition >= 0.75 AND `correctness.no_code_changed` is MET.
