## Criteria

### correctness.file_exists

**Question:** Does `client/src/hooks/useDebounce.ts` exist after the run, with an export named `useDebounce`?
**Evidence required:** file path + line number of the `export ... useDebounce` declaration.
**Verdict scale:** `MET` — export present and named correctly; `UNMET` — file missing or export absent; `PARTIAL` — exists with a different name or path casing.

### correctness.generic_signature

**Question:** Is the hook signature generic such that the callback's parameter and return types are preserved?
**Evidence required:** quoted signature with the generic type parameter (e.g. `<T extends (...args: any[]) => any>`).
**Verdict scale:** `MET` — generic parameter used and applied to both input and return; `PARTIAL` — generic declared but not threaded through return; `UNMET` — typed as `Function` or `any`.

### correctness.cleanup_on_unmount

**Question:** Does the hook clear any pending timer on unmount (e.g. via `useEffect` cleanup)?
**Evidence required:** quoted lines showing `clearTimeout` (or equivalent) inside an effect cleanup.
**Verdict scale:** `MET` — cleanup present and references the timer ref; `PARTIAL` — cleanup present but does not reference the actual timer; `UNMET` — no cleanup.

### correctness.tests_pass

**Question:** Does the Vitest spec at `client/src/hooks/useDebounce.test.ts` exist and pass?
**Evidence required:** \`programmatic_signals\` block showing test-runner exit code 0 and the test file path in `files_changed`.
**Verdict scale:** `MET` — file exists AND tests pass; `PARTIAL` — file exists but at least one test fails; `UNMET` — no test file.

### correctness.typecheck_clean

**Question:** Did `npx tsc --noEmit` exit 0?
**Evidence required:** quoted log line showing the typecheck-runner exit code.
**Verdict scale:** `MET` — exit 0; `UNMET` — non-zero or not run; `PARTIAL` — exit 0 but with deprecation warnings.

### decomposition.sub_dispatches

**Question:** Did `fullstack-dev` dispatch at least two distinct micro-agents (e.g. function-writer + test-writer)?
**Evidence required:** \`programmatic_signals.sub_dispatches\` count and the extracted target-agent names.
**Verdict scale:** `MET` — >= 2 distinct micro-agent targets; `PARTIAL` — exactly 1; `UNMET` — 0.

### decomposition.beads_graph

**Question:** Does the beads graph show a parent issue with at least two child issues created during the run?
**Evidence required:** diff between `beads-pre.json` and `beads-post.json`, listing new issue IDs and dependency edges.
**Verdict scale:** `MET` — parent + 2 children with dependency edges; `PARTIAL` — children created but no dependency edges; `UNMET` — no new issues.
