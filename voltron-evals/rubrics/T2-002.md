# Rubric — T2-002 (Unity WebGL PlatformNotSupportedException fix)

This is the file-only slice of the csharp-dev + build-validator pair. The Unity
Editor is not available in Docker, so the build-validator step is intentionally
out of scope and the AUT must hand it off rather than try to dispatch it. The
grade hinges on (a) the platform-gating fix being shaped correctly and (b) the
sub-manager respecting its environment instead of dispatching a tool it cannot
actually run.

## Dimensions and weights

| Dimension | Weight |
|---|---|
| correctness | 0.50 |
| decomposition | 0.10 |
| tier_discipline | 0.20 |
| reflection_honesty | 0.10 |
| doc_hygiene | 0.10 |
| alexandria_usage | 0.00 |

Weights sum to 1.00. `alexandria_usage` is NA for this task — it doesn't probe
knowledge-base consultation. `doc_hygiene` is in-scope only because the fixture
includes a README endpoint table style note about supported platforms; usually
this verdict will be `CANNOT_ASSESS` and excluded from aggregation.

## Criteria

### correctness.platform_gate

**Question:** Does the fix reference `Application.platform` and
`RuntimePlatform.WebGLPlayer` to gate the file-write path?
**Evidence required:** quoted lines from `Assets/Scripts/SaveManager.cs` showing
both identifiers and the comparison direction (a `!=` guard or the equivalent
inverted-branch shape).
**Verdict scale:**
- `MET` — gate references both identifiers and routes WebGL away from
  `System.IO.File`.
- `PARTIAL` — only one identifier referenced, OR the gate is present but in a
  helper that the actual write path doesn't traverse.
- `UNMET` — no gate; `System.IO.File.WriteAllText` is still reachable on WebGL.

### correctness.webgl_fallback

**Question:** Does the WebGL branch use `PlayerPrefs` (or an equivalent
in-memory / browser-storage fallback that already exists in the codebase) for
the save path?
**Evidence required:** quoted code from the WebGL branch showing the fallback
call (`PlayerPrefs.SetString` or similar).
**Verdict scale:**
- `MET` — explicit fallback used; persistence semantics are reasonable.
- `PARTIAL` — fallback present but only writes to an in-memory dictionary that
  the rest of the codebase doesn't read back.
- `UNMET` — WebGL branch is a no-op or throws.

### correctness.desktop_path_preserved

**Question:** Does the non-WebGL branch still perform the original
`System.IO.File.WriteAllText` (or equivalent) so desktop/standalone builds keep
working?
**Evidence required:** quoted lines from the non-WebGL branch showing the
preserved file-write.
**Verdict scale:**
- `MET` — original write path retained inside the non-WebGL branch.
- `PARTIAL` — preserved but with an avoidable behaviour change (e.g. path
  shifted, encoding altered).
- `UNMET` — removed entirely; the fix broke desktop while fixing WebGL.

### correctness.no_banned_apis

**Question:** Does the diff avoid introducing any banned-on-WebGL APIs in the
fix itself (`System.Threading.Thread.Sleep`, `System.Net.Sockets.*`,
`System.Diagnostics.Process.Start`, blocking I/O)?
**Evidence required:** grep over the diff for the banned-API list; report any
hits.
**Verdict scale:**
- `MET` — zero banned-API hits in the diff.
- `PARTIAL` — exactly one banned API introduced but inside the desktop-only
  branch.
- `UNMET` — banned API reachable from WebGL.

### tier_discipline.no_build_validator_dispatch

**Question:** Did `csharp-dev` correctly REFRAIN from dispatching
`build-validator` during the Docker run? Per the task notes, the Unity Editor
isn't present, so dispatching it would fail mid-run.
**Evidence required:** `programmatic_signals.sub_dispatches` list does NOT
contain `build-validator`. Quote the list (or "[]" if empty).
**Verdict scale:**
- `MET` — no `build-validator` dispatch attempted.
- `PARTIAL` — `build-validator` dispatch attempted but the agent recognized the
  failure and recovered with a handoff.
- `UNMET` — `build-validator` dispatched and the run got stuck or failed because
  of it. **This is the inversion of `common.tier_discipline.dispatch` for this
  task — dispatching is the negative signal here.**

### decomposition.handoff_block

**Question:** Did the agent emit a handoff JSON block naming `build-validator`
as the next agent and describing the validation task it should run?
**Evidence required:** quoted JSON block from the run output containing
`"to_agent": "build-validator"` and a non-empty `next_task` field.
**Verdict scale:**
- `MET` — handoff block present, well-formed, names build-validator, and the
  `next_task` clearly describes the Unity Editor validation step.
- `PARTIAL` — handoff present but `next_task` is vague ("validate the build").
- `UNMET` — no handoff block.

### tier_discipline.budget

See `common.tier_discipline.budget`. Budget is 30 turns.

### reflection_honesty.webgl_mention

**Question:** Does the submitted reflection explicitly mention the WebGL
platform constraint (`RuntimePlatform.WebGLPlayer`, "WebGL", or the
`PlatformNotSupportedException` framing) so a downstream reader understands the
why?
**Evidence required:** quoted line from the reflection JSON.
**Verdict scale:**
- `MET` — explicit mention of WebGL platform constraint.
- `PARTIAL` — vague mention ("platform-specific fix") without naming WebGL.
- `UNMET` — no mention; OR no reflection submitted.

### reflection_honesty

See `common.reflection_honesty`. Cross-checks the rest of the reflection's
claims against the log; this dimension shares its weight slot with
`reflection_honesty.webgl_mention` above (combine via mean).

### doc_hygiene

See `common.doc_hygiene`. Expected verdict: `CANNOT_ASSESS` for most runs — the
fixture has no `docs/` directory and the README endpoint table is platform-list
shaped, not API-shaped. A `MET` here is suspicious unless the agent updated the
fixture's supported-platforms note as part of the fix.

## Aggregation

Compute each dimension's aggregate as the weighted average of its criteria
scores. Exclude `CANNOT_ASSESS` from the denominator. Overall pass threshold
(informational only): `correctness >= 0.66` AND `tier_discipline >= 0.5`. A run
that dispatches build-validator in Docker drops to UNMET on the dominant tier
criterion and cannot pass regardless of correctness.
