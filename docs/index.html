Project Voltron

A team of specialized Unity subagent templates for Claude Code, served via MCP.

MCP Server Unity Claude Code 5 Agents MIT License

The Agent Team

Scene Architect @agent-scene-architect

GameObject hierarchy, prefabs, scene composition, transforms, and components. Builds the world.

C# Dev @agent-csharp-dev

MonoBehaviours, ScriptableObjects, gameplay systems, and editor tools. Writes clean, performant Unity C#.

Shader Artist @agent-shader-artist

Shaders, materials, VFX Graph, post-processing, and render features. Knows URP, HDRP, and Built-in.

Build Validator @agent-build-validator

Console monitoring, compile checks, Play Mode smoke tests, pre-commit validation. Read-only watchdog.

Asset Manager @agent-asset-manager

Folder structure, import settings, naming conventions, and project audits. Keeps things organized.

Quick Start

1

Clone

Get the source:

git clone https://github.com/7ports/project-voltron.git
cd project-voltron
npm install
2

Register

Add as a global MCP server:

claude mcp add --scope user \
  project-voltron -- \
  node /path/to/project-voltron/src/index.js
3

Scaffold

In any Unity project, ask Claude:

"Scaffold this project with Voltron agents"

MCP Tools

ToolDescription
list_templates List all available templates with descriptions and destinations
get_template Retrieve the full content of a specific agent template or CLAUDE.md
scaffold_unity_project Get all files needed to scaffold a Unity project with the full agent team
get_agent_usage_guide Usage guide for invoking and coordinating agents

Recommended Workflow

1
Scaffold Run scaffold_unity_project to write CLAUDE.md + all agent files
|
2
Configure Fill in CLAUDE.md with your project name, Unity version, render pipeline, etc.
|
3
Develop Invoke agents as needed: csharp-dev for scripts, scene-architect for hierarchy, shader-artist for visuals
|
4
Validate Always run build-validator before committing to catch errors early
